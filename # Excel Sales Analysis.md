# Excel Sales Analysis

## Overview
This project demonstrates data cleaning, analysis, and dashboard creation using Microsoft Excel.

## Dataset
A sales dataset containing product sales, quantities, prices, dates, and salesperson information.

## Tasks Performed
- Standardized inconsistent product names
- Standardized salesperson names
- Removed duplicate records
- Created Total Sales calculations
- Built Pivot Tables
- Created a Dashboard

## Key Insights
- Total Revenue: ₹21,324
- Top Product: Pencil
- Top Product Revenue: ₹6,240
- Top Salesperson: Aman
- Average Order Value: ₹176.23
